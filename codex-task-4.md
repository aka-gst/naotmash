# Заказ: поле, предметы и укрытия

Дополнение к `codex-task-3.md` — тот заказ остаётся в силе целиком, этот
добавляется к нему. Здесь всё нужное для перехода от одной комнаты к
**полю, по которому ходят**: игрок бродит по большой карте, камера едет за
ним, вокруг разбросаны предметы и препятствия.

Правила из третьего заказа действуют без изменений, повторю коротко самое
дорогое: **`xmlns` обязателен в каждом SVG** (без него браузер не декодирует
файл как картинку, и спрайт молча не появляется в игре); части тела, а не
кадры анимации; манифест в формате `{ "имя-без-расширения": { "w":N, "h":N,
"pivot":[доля, доля] } }`.

---

## 1. Земля — вместо шума нужна структура

Сейчас в игре четыре бесшовные текстуры 256×256, и они честно выполняют
задание: тёмные, низкоконтрастные, разброс яркости меньше 12%. На одном
экране это работало. Для поля, по которому ходят, этого мало: идёшь минуту
и не понимаешь, сдвинулся ли вообще, потому что шум везде одинаковый.

Нужны **крупные тайлы со структурой** — швы, стыки плит, борозды, трещины,
русла. Не узор в мелкую крапинку, а рисунок, по которому глаз считывает
перемещение.

| Файл | Что |
|---|---|
| `field-yard.png` | утоптанный двор: колеи, вытоптанные тропы, доски |
| `field-ice.png` | лёд: крупные трещины, полыньи, наплывы |
| `field-hall.png` | чертог: большие плиты с чёткими швами, ковровая дорожка |
| `field-ash.png` | пепелище: борозды, потёки, выгоревшие пятна |

Каждый — **512×512 PNG, бесшовный по обеим осям**, не больше 60 КБ.
По-прежнему **тёмный**: поверх него бегает до тридцати фигур, и они должны
читаться. Но разброс яркости можно поднять до 20% — структура важнее
абсолютной ровности.

Палитры прежние: двор `#12160f`→`#33402a`, лёд `#0c131a`→`#2b4d61`,
чертог `#15100c`→`#4a3220`, пепелище `#121110`→`#3b332c`.

## 2. Крупные приметы местности

Чтобы поле не было равномерным, по нему расставляются заметные объекты. Это
не препятствия, а ориентиры: увидел издалека — понял, где ты.

По три на биом, SVG с прозрачностью, размеры 120–220:

- `land-yard-1..3` — телега, поленница, колодец
- `land-ice-1..3` — вмёрзшая лодка, торос, прорубь
- `land-hall-1..3` — колонна, длинный стол, очаг
- `land-ash-1..3` — обгорелое дерево, остов дома, куча золы

## 3. Предметы, которые ищут

Главное, ради чего затевается поле: на нём есть что подбирать.

| Файл | Размер | Что |
|---|---|---|
| `item-chest-closed` | 54×44 | сундук закрытый |
| `item-chest-open` | 54×44 | он же открытый, та же посадка |
| `item-gem-small` | 18×18 | самоцвет, мелкий |
| `item-gem-mid` | 26×26 | средний |
| `item-gem-big` | 36×36 | крупный |
| `item-coin` | 22×22 | монета |
| `item-flask` | 26×34 | склянка (лечение) |
| `item-key` | 30×20 | ключ |
| `item-horn` | 40×32 | рог (призыв, механики пока нет) |
| `item-rune` | 28×28 | руна (усиление, механики пока нет) |

Самоцветы — три размера **одной формы**, они отличаются только величиной и
цветом: мелкий `#6ec6a0`, средний `#5aa6e0`, крупный `#c86ee0`. Всё
остальное — разные силуэты.

## 4. Указатель на предмет за краем экрана

Когда предмет вне видимой части поля, у края появляется стрелка. Нужен один
файл `ui-pointer.svg`, 28×28, остриём **вверх**, одноцветный
`fill="currentColor"` — код повернёт и покрасит сам.

## 5. Препятствия — уточнение к третьему заказу

В `codex-task-3.md` заказаны `obstacle-barrel`, `obstacle-crate`,
`obstacle-pillar`, `obstacle-brazier`. К ним добавь по **разбитой версии**:
`obstacle-barrel-broken` и так далее, тех же размеров и с той же посадкой.
Их можно бить оружием и швырять в них врагов — механика броска в игре уже
есть, нужна только вторая картинка.

## Самопроверка — приложи вывод

1. `grep`: у каждого SVG есть `xmlns`, ни в одном нет `<image`, `<filter`,
   `<mask`, `xlink:href`;
2. каждый SVG парсится (`xmllint --noout`);
3. для каждого `field-*.png` — программная проверка бесшовности по обеим
   осям и разброс яркости в процентах;
4. размер каждого файла и суммарный;
5. манифест в указанном формате на каждый новый файл.

## Как отдать

Архив: `sprites/*.svg`, `field/*.png`, `sprites.json` только с новыми
записями.

Если придётся резать ради объёма — режь в таком порядке: сначала руна и рог,
потом приметы местности, потом разбитые версии препятствий. Тайлы поля и
предметы нужны целиком, без них переход к полю не имеет смысла.
